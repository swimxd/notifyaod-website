# NotifyAOD website

Public privacy policy and support for NotifyAOD, by Ali H. Adapted from the owner's `swimxd/blurb-website` layout: plain HTML/CSS, system fonts, automatic dark mode, and GitHub Pages.

- Website: https://swimxd.github.io/notifyaod-website/
- Privacy policy: https://swimxd.github.io/notifyaod-website/privacy.html
- Support: https://swimxd.github.io/notifyaod-website/support.html

GitHub Pages publishes `main` from the repository root. There is no JavaScript, analytics, form backend, external font, or app download in this repository. It contains no Android app source or signing material.

The privacy policy describes NotifyAOD 1.1.1 (`com.notifyaod.app`) and was checked against its manifest, notification adapter, local preferences/recovery stores, diagnostics, privileged bridge and optional accessibility service on September 17, 2026. Notification data remains local; website hosting and user-initiated support messages have separate handling described in the policy. Keep the text current if data practices change.

The developer contact uses the existing public support inbox, `blurbapp.support@gmail.com`; messages should identify NotifyAOD. NotifyAOD 1.1.1 includes in-app privacy, support and public issue links. Publishing this website does not publish the app or complete Play declarations.

Preview locally with any static HTTP server, for example `python -m http.server 8080`, then open http://localhost:8080/.
